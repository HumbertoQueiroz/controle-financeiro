# 9. Relatórios

Em **Mais → Relatórios**. É a visão consolidada das suas contas, sem recorte de mês.

## Os três modos

| Modo          | Mostra                                 |
| ------------- | -------------------------------------- |
| **Ambos**     | A pagar, a receber e o **saldo final** |
| **A pagar**   | Só o que você deve                     |
| **A receber** | Só o que têm a lhe pagar               |

O saldo final só aparece no modo **Ambos**. Nos outros ele não é calculado, porque um saldo
com um lado faltando seria um número que parece saldo e não é.

## Incluir quitadas

Por padrão o relatório mostra só o que está **em aberto**. O botão **Incluir quitadas** traz
também o que já foi pago.

As quitadas aparecem na lista mas **somam zero** no total — o que falta delas é zero. Elas
servem para consulta e conferência, não para inflar o total.

## O que cada linha traz

| Coluna        | Observação                                                                    |
| ------------- | ----------------------------------------------------------------------------- |
| **Descrição** | O que é                                                                       |
| **Com quem**  | A outra ponta. **"Cartão"** significa a instituição do cartão, não uma pessoa |
| **Origem**    | Fatura, repasse, rateio, recorrente ou manual                                 |
| **Vence**     | A data de vencimento                                                          |
| **Valor**     | **O que ainda falta**, não o valor original                                   |

A última coluna merece atenção: uma dívida de R$ 100 com R$ 60 já pagos aparece como
**R$ 40**. Mostrar o valor cheio faria você parecer dever mais do que deve.

No celular cada linha vira um cartão empilhado; no computador, uma tabela. A coluna
"Origem" some no celular, onde não cabe e não é essencial.

## O que entra no seu relatório

Tudo que está em seu nome, **inclusive o que outra pessoa lançou**.

Se a Ana registrou que você deve R$ 50 do rolê, isso aparece no **seu** relatório, na sua
conta. Não é preciso ela avisar nem você lançar de novo: é o mesmo registro, visto do outro
lado.

Obrigações canceladas ficam de fora em todos os modos — não são dívida de ninguém.

## Ver o relatório de outra pessoa

É possível quando alguém compartilhou com você. O que você enxerga é **exatamente** o escopo
que a pessoa concedeu: com um acesso de "somente a pagar", o lado "a receber" nem é
consultado — não é escondido na tela, não é buscado.

Se ela retirar o acesso, ele para de funcionar na mesma hora.
