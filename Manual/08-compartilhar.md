# 8. Compartilhar relatórios

Em **Mais → Compartilhar**.

**Quem decide quem vê seus números é você.** Ninguém tem acesso aos seus relatórios sem que
você tenha concedido, e você pode tirar o acesso a qualquer momento.

## Escolher o que a pessoa vê

| Escopo                           | O que a pessoa enxerga |
| -------------------------------- | ---------------------- |
| **Somente contas a pagar**       | O que você deve        |
| **Somente contas a receber**     | O que têm a lhe pagar  |
| **A pagar, a receber e o saldo** | Tudo                   |

O escopo é escolhido **antes** do e-mail, e vale para os dois caminhos abaixo.

## Compartilhar

Preencha o e-mail de quem vai ver e toque em **Compartilhar**. O sistema resolve os dois
casos sozinho:

### A pessoa já tem conta

O acesso é concedido na hora. Ela passa a ver o seu relatório no escopo escolhido, sem
precisar aceitar nada.

### A pessoa não tem conta

O sistema gera um **convite** e abre um diálogo:

1. O link já foi **copiado** para a área de transferência.
2. O link também aparece num campo, com botão de copiar — use se a cópia automática não
   funcionar no seu navegador.
3. Dois botões: **Enviar por WhatsApp** e **Sair**.

**O sistema não envia nada sozinho.** Quem entrega o link é você, pelo canal que você já
usa. Disparar mensagem para terceiros como efeito colateral de uma busca seria ruim
justamente quando alguém digita o e-mail errado.

O botão do WhatsApp abre o aplicativo com a mensagem pronta. Se você preencheu o campo de
WhatsApp, já vai para aquele número; sem ele, você escolhe o contato dentro do app.

### Campos opcionais

| Campo                      | Para que serve                                            |
| -------------------------- | --------------------------------------------------------- |
| **WhatsApp**               | Abrir a conversa já no contato certo. 11 dígitos, com DDD |
| **É alguém da sua lista?** | Ligar o convidado a uma pessoa que você já cadastrou      |

O segundo campo é o que faz diferença de verdade: ao aceitar, essa pessoa passa a ver **as
contas que você já lançou no nome dela**. Sem o vínculo, ela entra e vê uma tela vazia, mesmo
devendo a você.

## O link do convite

- Vale **uma vez só**. Depois de aceito, não serve para mais ninguém.
- Expira em **7 dias**.
- Só funciona para o e-mail convidado — quem receber o link encaminhado não consegue usá-lo
  com outro endereço.

> **Trate o link como uma senha.** Quem o abrir pode se cadastrar com o e-mail convidado e
> ver o que você autorizou.

Convidar o mesmo e-mail de novo **substitui** o convite anterior: o link antigo deixa de
funcionar. É o comportamento esperado de "reenviar", e evita dois links válidos circulando.

## Ver e retirar acessos

A lista mostra, junto:

| Tipo                 | O que é                                     |
| -------------------- | ------------------------------------------- |
| **Concedido**        | Já tem acesso                               |
| **Convite pendente** | Ainda não aceitou, com a data em que expira |

Os dois aparecem porque **convite pendente é acesso futuro** — escondê-lo faria você
acreditar que compartilhou com menos gente do que compartilhou.

O ícone de lixeira retira o acesso. Em um convite pendente, ele invalida o link antes do
aceite. **A retirada tem efeito imediato**: na consulta seguinte, a pessoa já não enxerga
nada.

## Quem mais pode ver
